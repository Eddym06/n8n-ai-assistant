1. 🏗️ ARQUITECTURA DEL AGENTE
=============================

El agente V3 tiene estas partes principales:

📁 COMPONENTES PRINCIPALES:
- initializeSupportedNodeTypes(): Registra todos los tipos de nodos soportados
- initializeContextPatterns(): Patrones para detectar contexto del workflow
- initializeConfigTemplates(): Templates de configuración por tipo de nodo
- configureWorkflowNodes(): Método principal de configuración
- generateConfigurationWithGemini(): Configuración inteligente con IA

📁 ESTRUCTURA DE DATOS:
```javascript
this.supportedNodeTypes = {
  triggers: ['webhook', 'cron', 'emailTrigger', ...],
  processors: ['function', 'set', 'if', 'switch', ...],
  integrations: ['hubspot', 'googleSheets', 'postgresql', ...],
  // ... más categorías
}

this.contextPatterns = {
  'e-commerce': ['pedido', 'orden', 'producto', 'inventario', ...],
  'crm': ['cliente', 'contacto', 'lead', 'deal', ...],
  // ... más dominios
}
```

2. ➕ AGREGAR NUEVOS TIPOS DE NODOS
==================================

Para agregar soporte a un nuevo nodo:

PASO 1: Registrar el tipo de nodo
```javascript
// En initializeSupportedNodeTypes()
return {
  triggers: [
    // ... nodos existentes
    'n8n-nodes-base.NUEVO_NODO_TRIGGER'
  ],
  integrations: [
    // ... nodos existentes  
    'n8n-nodes-base.NUEVA_INTEGRACION'
  ]
}
```

PASO 2: Crear template de configuración
```javascript
// En initializeConfigTemplates()
'n8n-nodes-base.NUEVO_NODO': {
  defaultParameters: {
    // Parámetros por defecto
    operation: 'create',
    resource: 'item'
  },
  contextualParameters: {
    'e-commerce': {
      // Parámetros específicos para e-commerce
      operation: 'createOrder',
      fields: ['customer_email', 'total_amount']
    }
  },
  credentialsRequired: ['nuevaIntegracionApi']
}
```

PASO 3: Implementar lógica de configuración
```javascript
// En configureNode() agregar case
case 'n8n-nodes-base.NUEVO_NODO':
  return this.configureNuevoNodo(node, context, workflow);

// Método específico
configureNuevoNodo(node, context, workflow) {
  const baseConfig = this.configTemplates['n8n-nodes-base.NUEVO_NODO'];
  
  // Aplicar configuración contextual
  if (context.domain === 'e-commerce') {
    node.parameters = {
      ...baseConfig.defaultParameters,
      ...baseConfig.contextualParameters['e-commerce']
    };
  }
  
  return true;
}
```

5. 🔗 AGREGAR NUEVAS INTEGRACIONES
=================================

Para agregar soporte a una nueva API/servicio:

PASO 1: Definir configuración de integración
```javascript
// En initializeConfigTemplates()
'n8n-nodes-base.NUEVA_API': {
  defaultParameters: {
    operation: 'create',
    resource: 'record'
  },
  authentication: {
    type: 'api_key',  // o 'oauth2', 'basic'
    fields: ['apiKey', 'apiSecret']
  },
  operations: {
    create: { method: 'POST', endpoint: '/api/records' },
    read: { method: 'GET', endpoint: '/api/records/{id}' },
    update: { method: 'PUT', endpoint: '/api/records/{id}' },
    delete: { method: 'DELETE', endpoint: '/api/records/{id}' }
  }
}
```

PASO 2: Implementar configuración específica
```javascript
configureNuevaApi(node, context, workflow) {
  const config = this.configTemplates['n8n-nodes-base.NUEVA_API'];
  
  // Configurar operación según contexto
  let operation = 'create';
  if (context.intent.includes('obtener') || context.intent.includes('buscar')) {
    operation = 'read';
  } else if (context.intent.includes('actualizar')) {
    operation = 'update';
  }
  
  node.parameters = {
    operation,
    url: config.operations[operation].endpoint,
    method: config.operations[operation].method,
    headers: {
      'Content-Type': 'application/json',
      'Authorization': '={{$credentials.NUEVA_API.apiKey}}'
    }
  };
  
  node.credentials = { NUEVA_API: 'YOUR_NUEVA_API_CREDENTIALS' };
  
  return true;
}
```

PASO 2: Procesador de templates
```javascript
processTemplate(templateName, context, nodeData) {
  const template = this.advancedTemplates[templateName];
  if (!template) return null;
  
  let processed = template.template;
  
  // Reemplazar variables
  Object.entries(template.variables).forEach(([key, value]) => {
    const placeholder = `{{${key}}}`;
    processed = processed.replace(new RegExp(placeholder, 'g'), value);
  });
  
  // Procesar condicionales simples
  processed = this.processConditionals(processed, context);
  
  return processed;
}
```

PASO 2: Validador de configuraciones
```javascript
validateConfiguration(node, nodeType) {
  const validators = {
    'n8n-nodes-base.webhook': (params) => {
      return !!(params.httpMethod && params.path);
    },
    
    'n8n-nodes-base.function': (params) => {
      return !!(params.functionCode || params.jsCode);
    },
    
    'n8n-nodes-base.httpRequest': (params) => {
      return !!(params.url && params.method);
    }
  };
  
  const validator = validators[nodeType];
  return validator ? validator(node.parameters) : true;
}
```
