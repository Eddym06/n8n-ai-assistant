Crea un sistema de automatización empresarial avanzado que procese pedidos de e-commerce desde múltiples canales (webhook, email, Telegram), valide los datos del cliente y producto, calcule precios y descuentos dinámicamente, integre con el CRM de HubSpot para gestionar leads, envíe confirmaciones personalizadas por email y Telegram, genere facturas automáticamente en PDF, actualice el inventario en Google Sheets, programe seguimientos de entrega, maneje excepciones y errores con notificaciones a administradores, registre toda la actividad en una base de datos PostgreSQL, y finalmente envíe reportes diarios de ventas por email y Slack. El sistema debe incluir lógica de validación robusta, manejo de errores, procesamiento paralelo para múltiples pedidos, y configuraciones de retry para APIs externas.
