# 🎯 CARPETA OFICIAL - n8n AI Assistant System

## 📁 Estructura Organizada del Sistema Oficial

Esta carpeta contiene todos los componentes necesarios para ejecutar el **n8n AI Assistant System** de forma completamente independiente y organizada.

### 🏗️ **Arquitectura del Sistema**

```
Oficial/
├── 🚀 extension-server-OFICIAL.js          # Servidor principal
├── 🤖 ultra-intelligent-fallback-agent-v2.js # Agente ultra inteligente
├── 🧠 intelligent-agent-main.js            # Agente principal
├── 🔧 intelligent-workflow-agent.js        # Agente de workflows
├── ⚡ workflow-validator.js                # Validador de workflows
├── 🛡️ validation-system.js                 # Sistema de validación
├── 📋 package.json                         # Dependencias del proyecto
├── 🔐 .env                                # Variables de entorno
├── 📁 SISTEMA PRINCIPAL/                   # Agentes especializados
│   ├── 🎯 prompt-enhancement-agent.js      # Mejora de prompts
│   ├── 🔧 Herramienta-Autocorrector.js     # Autocorrector
│   ├── 🎨 intelligent-positioning-agent-v4-ai-enhanced.js
│   ├── 🤖 intelligent-node-config-agent-v3-enhanced.js
│   ├── 🧠 semantic-memory-agent.js         # Memoria semántica
│   ├── 📊 gemini-call-tracker.js           # Rastreador de llamadas
│   ├── 🔄 flow-coherence-agent-v2.js       # Coherencia de flujo
│   └── ... (otros agentes especializados)
├── 📁 generated-workflows/                 # Workflows generados
└── 📚 README-CARPETA-OFICIAL.md           # Esta documentación
```

### 🎯 **Componentes Principales**

#### 🚀 **Servidor Principal**
- **`extension-server-OFICIAL.js`**: Servidor principal que orquesta todo el sistema
- Integra todos los agentes y sistemas de validación
- Maneja la generación completa de workflows
- Incluye sistema de posicionamiento profesional

#### 🤖 **Agentes Inteligentes**
- **Ultra Intelligent Agent V2**: Generación avanzada de workflows
- **Prompt Enhancement Agent**: Mejora automática de prompts
- **Intelligent Positioning Agent V4**: Posicionamiento profesional
- **Flow Coherence Agent V2**: Validación de coherencia
- **Semantic Memory Agent**: Memoria y aprendizaje
- **Herramienta Autocorrector**: Corrección automática

#### 🛡️ **Sistemas de Validación**
- **Workflow Validator**: Validación completa de workflows
- **Validation System**: Sistema de validación integrado
- **Intelligent Workflow Validator**: Validación inteligente

### ⚙️ **Uso del Sistema**

#### 🚀 **Inicio Rápido**
```bash
# Navegar a la carpeta Oficial
cd Oficial

# Ejecutar el sistema con un prompt
node extension-server-OFICIAL.js "tu prompt aquí"
```

#### 📝 **Ejemplos de Uso**
```bash
# Workflow simple
node extension-server-OFICIAL.js "crear workflow de email automation"

# Workflow complejo
node extension-server-OFICIAL.js "workflow empresarial con webhook, validación, CRM, notificaciones múltiples y reportes"

# Workflow específico
node extension-server-OFICIAL.js "sistema de onboarding: webhook recibe usuario, valida datos, crea en base de datos, envía email de bienvenida, programa reunión y notifica equipo"
```
